# Desktop redesign mockups

`desktop-redesign.html` is a standalone, Bionic-inspired direction for A-Coder Desktop.

Open it directly in a browser, or serve it from the desktop app dev server:

```bash
cd desktop-app
npm run dev
# http://127.0.0.1:1426/design/desktop-redesign.html
```

What to look at:

- **Hero** — a light, editorial product page built around a floating A-Coder window on a scenic backdrop.
- **Workspace** — click `Workspace`, `Open A-Coder Desktop`, or any "Open..." link to expand the same window into a full desktop view. `Esc` or `Overview` returns.
- The window itself is the redesign: projects, conversation, edited files, and a live browser preview in one surface.

There is no build step and no external asset dependency.
